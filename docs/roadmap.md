# Roadmap

## Current Groundwork

- Define observable per-turn feature objects.
- Track conversation-local baselines.
- Emit structured metadata beside transcript text.
- Keep the first implementation dependency-light and easy to test.

## Next Experiments

- Add adapters for real speech-recognition timing data.
- Evaluate which features help downstream language-model responses.
- Explore rolling-window baselines for long conversations.
- Add privacy checks for persistence boundaries.
- Provide examples for CLI, server, and streaming use cases.
